## Notes for CRAN maintainers
`CohortEconomics` provides an analytical pipeline for Observational Medical Outcomes Partnership (OMOP) Common Data Model (CDM) cohorts, featuring high-dimensional propensity score adjustment, longitudinal health-state trajectory modeling, Markov microsimulations, and Cost-Effectiveness Analysis (CEA) using 'BCEA'. It depends on the standalone companion packages 'CohortUtilisation' and 'CohortCosts'.
